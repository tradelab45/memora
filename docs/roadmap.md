# Milestones

1. **Working first chapter:** editorial website, responsive People/Memory/Book sections, procedural book, scroll effects, sample story studio, foundation scaffolds.
2. **Manual mobile story MVP:** platform runners, encrypted local database, selected OS photo permissions, Inner 3, one-line captions, local timeline and flipbook.
3. **Local intelligence:** enroll chosen people with 3–5 reference photos, device-only embeddings, duplicate/quality filtering, memory inbox.
4. **Consented cloud:** auth, validated consent receipts, selected media upload, repository adapters, export and deletion lifecycle.
5. **Living magazine:** deterministic page templates, event grouping, monthly/person/trip/annual books, durable worker and PDF export.
6. **Optional AI:** approved suggestions using explicit user context; no invented emotions or events.
7. **Private collaboration:** scoped/revocable shares and membership authorization, not public bucket URLs.
8. **Print and premium:** provider integration, validated webhooks, IAP/Stripe entitlements, approved print proofs.
